# 影巢趋势

影巢趋势是一个轻量的 Mediary 插件。它每 6 小时读取公开 TG 频道
oneonefivewpfx，筛选已确认的影巢官组发布者，从消息中读取 TMDB ID，再按 Mediary 的二级分类创建订阅。

## 特性

- 不需要影巢账号、Cookie 或 TG Bot Token；
- 默认识别白可乐、冷、新疆美味三文鱼、Pluto、最爱你的人望眼欲穿；
- 配置页动态读取每台 Mediary 自己的二级分类；
- 官组消息先按媒体类型和 TMDB ID 合并，同一影视只处理一次；
- 已有同一电影或剧集订阅时跳过；
- 记录已处理的 TG 消息，重复执行不会重复订阅。

## 配置

安装并启用后，重新打开插件配置即可读取当前 Mediary 的二级分类，再按需勾选。默认检查周期为
0 */6 * * *，即每 6 小时一次。
如果影巢新增了官组发布者，可在“官组发布者”中用英文逗号追加昵称。

频道页面是公开 HTML，插件不会发送消息、上传数据或保存频道内容，只保存消息 ID 和处理结果。
