# 豆瓣将映

定时读取 RSSHub 的豆瓣即将播出剧集，达到想看人数阈值后通过 Mediary 匹配 TMDB，按当前季
开播日期自动创建订阅，并可在开播前发送一次提醒。

本插件采用 GPL-3.0 许可证。

## 行为说明

- RSS 路由为 `/douban/tv/coming/<sort>/<count>`；
- 季号支持“第二季”、`S2` 和 `Season 2` 等标题；
- 订阅前检查相同 TMDB ID 与季号，重复运行不会重复创建；
- 提醒按“豆瓣 ID + 季号 + 开播日期”去重；
- 历史数据仅写入 Mediary 提供的插件数据目录。

## 外部服务

- 用户配置的 RSSHub 实例：获取豆瓣即将播出条目、简介和想看人数；
- Mediary/TMDB：媒体识别、季信息和开播日期；
- Mediary 通知渠道：发送开播提醒。

本插件不收集遥测，也不会把 Mediary Token 或本机配置发送给 RSSHub。
