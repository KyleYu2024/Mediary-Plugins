# Emby 用户迁移

这是 **Mediary 插件 + Mediary 主程序迁移服务**，需要包含迁移接口的新版主程序。Lux 插件不能直接安装到 Mediary。本实现独立编写，通过 Emby HTTP API 读取，不修改 Emby，也不直接操作正在运行的 Emby 数据库。

## 迁移范围与边界

| 数据 | 行为 |
| --- | --- |
| 用户名 | 创建普通媒体用户；可重命名、选择源用户，或明确映射到现有普通用户 |
| 原密码 | 新用户首次登录向原 Emby 验证用户名、密码及返回用户 ID，成功后保存本地哈希，以后脱离 Emby；支持空密码及超过 bcrypt 72 字节的原密码 |
| 账户禁用 | 保留源用户禁用状态；源管理员不会获得 Mediary 后台管理权限 |
| 媒体库权限 | 映射到现有、已扫描的 Mediary 库，只授予已映射的源库，源“访问全部库”也固定为本次源库列表 |
| 已看、媒体收藏、续播位置 | 电影、电视剧、季、单集；位置按原始 ticks 保存 |
| 播放次数、最近播放时间 | 按源值保存，时间统一为 UTC 时间点，客户端按自己的时区显示 |
| 演员收藏 | 通过 TMDB 演员 ID 对应 Mediary 已有演员；支持查询及取消收藏 |
| 逐次播放记录、累计观看时长 | Emby 聚合 UserData 不含这些明细，不从播放次数伪造历史或时长 |
| 用户头像、客户端偏好、特殊 Policy、家长控制 | 保留源用户接口返回的资料及 Policy 在快照/报告中，尚不作为 Mediary 对应功能生效；含无法等价执行的限制策略时，新账号保持禁用，管理员设置等价限制后再启用 |

**“完整”必须以预览报告为准。** 未匹配、冲突或不支持的数据不能算成功迁移。插件不会以片名猜测身份，也不会复用 Emby item ID 作为 Mediary item ID。匹配顺序为媒体库 + 类型 + 完整路径，再尝试 TMDB（剧集使用剧 TMDB ID + 季号 + 集号，支持第 0 季）。已知路径与 TMDB/季集身份相矛盾时拒绝匹配；多版本匹配不明确时需路径映射。

## 使用步骤

1. 在 Mediary 添加原媒体目录并完成扫描。现有 NFO/图片可使用“仅本地 NFO 和图片”模式复用。
2. 安装插件，授予迁移权限，在配置中**只填写 Emby 地址和 API Key**。不需要填写映射 JSON、用户 ID 或任务 ID。
3. 打开“迁移助手”。连接已配置时会自动识别：优先按一致的媒体库路径、唯一库名匹配，再尝试唯一且类型相同的库；一个目标有多个源库竞争时留给用户选择。
4. 界面显示双方媒体库名称，单一路径会自动对应。只在无法唯一确定时选择目标库/路径。
5. 默认勾选全部用户，沿用原用户名并创建媒体账号。已迁移账号自动复用上次映射。同名账号需要选择“创建独立媒体账号”（自动建议新名字，保留 Emby 密码）或“使用已有普通用户”（保留目标本地密码）；管理员不能作为迁移目标。可取消不需要迁移的用户。
6. 点击“生成迁移预览”。读取在主程序后台进行，界面持续显示状态，**预览不创建用户或修改观看状态**。媒体匹配冲突会在结果中列出。
7. 核对结果，勾选确认并点击“开始迁移”。默认存在未匹配数据时拒绝导入；主动勾选“跳过未匹配媒体及演员”才进行部分迁移。已有目标观看状态默认保留，选择覆盖时只覆盖预览后未改变的记录。
8. 新账号使用原 Emby 密码登录 Mediary 媒体服务。首次成功前保留原 Emby 在线；之后该账号本地认证。已经接管的本地密码不随源 Emby 后续改密变化。

“保存完整报告”把全部条目、源状态及源用户资料保存到插件 `data/migration-report.json`。界面仅展示有限的明细，报告包含全部记录；API Key 和登录返回的 AccessToken 不进入报告。重复提交同一任务不会重复创建账号。

自动识别只产生可核对的建议，不会自动覆盖账号、权限或播放进度。底层接口仍兼容显式映射，普通界面无需接触 JSON。

## 安全和恢复

- 预览通过完整分页读取；重复分页、提前结束、负数进度、无效日期或服务器身份变化会中止，未写入用户数据。
- 导入使用一个 SQLite 事务；失败或进程中断会回滚。重启后中断的读取任务标记失败，需重新预览；中断的导入回到可重试状态。
- 导入前再次验证目标媒体身份，避免预览后重扫/匹配改变了目标。
- 本地重设密码永久终止该用户的原密码桥接，旧 Emby 密码不能绕过本地重设。
- 源 API Key 只保存在插件秘密设置和主程序迁移源记录中；每个迁移源的待接管账号全部完成或本地重设后，主程序清除该源保存的 Key。插件设置里的 Key 由管理员自行清空。
- 明文密码只用于用户本次登录请求，不进入配置、快照、报告或日志。远端响应中的 AccessToken 不保存或返回。禁用重定向，避免凭据被转发到另一地址。
- 报告包含用户名、媒体状态和路径，是个人数据，按本地配置目录权限管理。
- 这是一次性导入，不是持续双向同步。迁移完成后两边的新播放不会自动合并。

## 开发验证

```bash
cargo test --manifest-path backend/Cargo.toml --locked --bin mediary-backend emby_user_migration
cargo test --manifest-path plugins/Cargo.toml --locked --bin emby-migration-plugin
```

插件入口是 `emby-migration-plugin`，安装目录中以 `plugin` 命名，与 `plugin.json` 放在一起。后端 API 需要专用迁移权限，也支持现有管理员 JWT / 主 API Token；普通媒体用户不能调用。
