# 无损音乐下载

在 Mediary 插件页中搜索音乐，将选中的音频异步下载到 NAS 挂载目录，并按歌名整理文件名。

## 使用

1. 将 NAS 音乐目录以可写方式挂载到 Mediary 容器，例如 `/media/music`。
2. 在插件设置中填写容器内的绝对路径。
3. 如果站点返回防护验证，在浏览器通过验证后，将该站的 Cookie 填入插件设置。Cookie 会被 Mediary 脱敏存储，插件不会记录它。
4. 打开插件，搜索歌名或歌手，点击结果中的“下载”。

提交后页面会显示下载任务卡片；点击“刷新状态”可查看下载百分比、完成路径或错误原因。

下载任务会先进入插件队列，不受普通动作 45 秒超时限制。后台进程先写入 `.part` 文件，成功后再原子更名。同名文件默认保留，新文件会自动加 ` (2)` 等后缀。

## 站点兼容性

首版内置 `flac.music.hi.cn` 的 `ajax.php?act=search` / `act=music` 接口适配，并对常见的字段名和包装层做了容错。“音乐站地址”可改成部署相同接口的镜像站；不同 API 的站点需要新增对应适配器。

qBittorrent 只处理 BitTorrent/磁力任务，无法下载普通 HTTP 音频直链，因此该插件使用自身后台下载器。
