# 豆瓣想看

同步一个或多个豆瓣用户最近标记为“想看”的电影和剧集，通过 Mediary 匹配 TMDB 后自动
创建订阅。实现参考 MoviePilot 官方插件仓库的
[`DoubanSync`](https://github.com/jxxghp/MoviePilot-Plugins/tree/main/plugins.v2/doubansync) 插件，
并适配为 Mediary v1 计划动作插件。

## 使用

1. 确认豆瓣账号的收藏可公开访问。
2. 从个人主页 `https://www.douban.com/people/<用户ID>/` 取得用户 ID。
3. 在插件配置中填写用户 ID；多个 ID 可用英文逗号、空格或换行分隔。
4. 授予目录读取、订阅读取和订阅写入权限，然后手动同步或等待计划任务。

插件只处理 RSS 标题以“想看”开头、链接指向豆瓣影视条目的记录。成功创建或确认已有
订阅后，豆瓣条目 ID 会写入历史，避免重复处理；识别失败的条目会在后续运行重试。
剧集季号支持“第二季”、“第2季”、`S2`、`Season 2`，以及豆瓣标题末尾的裸数字写法
（例如“庆余年2”）。插件会先通过 TMDB 季列表核实该季确实存在，再创建对应季订阅；
裸数字兜底仅对豆瓣已确认的剧集生效，不会影响电影。

## 与 MoviePilot 版本的差异

Mediary 当前公开插件 API 不提供站点聚合搜索下载、媒体库缺失检查和豆瓣用户到本地用户的
映射接口，因此本插件移植个人想看同步、最近天数、媒体识别、订阅和历史去重，不提供
“搜索下载优先”和用户归属映射。

## 数据与许可

- 豆瓣公开 interests RSS：读取用户最近收藏动作；
- 豆瓣公开移动端条目元数据：判断电影/剧集、年份和季号；
- Mediary/TMDB：解析媒体并创建订阅；
- 插件数据仅写入 Mediary 提供的数据目录，不收集遥测。
