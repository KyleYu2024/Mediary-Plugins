# 115 签到插件

使用插件自己配置的 115 Web Cookie 调用安卓端每日积分签到接口，可按
用户填写的 5 段 cron 表达式自动执行。

## 配置

1. 在浏览器登录 115，从任意已登录请求中复制完整 Cookie。
2. 在插件设置中填入 Cookie，至少需要包含 `UID`。
3. 设置 cron，默认 `5 0 * * *` 表示每天 00:05 执行。
4. 按需开启或关闭签到结果通知，然后启用插件。

Cookie 属于账号凭据，不要将它发到 issue、日志或截图中。插件会将该字段作为
secret 脱敏，且不会把 Cookie、UID 或请求 token 写入运行记录。

## 兼容性

该功能使用 115 安卓客户端的 `points_sign` 接口，不属于 115 公开 OpenAPI。
115 若调整签到接口或 token 算法，插件需要同步更新。旧版安卓/iOS 的
`takespc` “摇一摇领空间”接口已经下线，因此不会作为回退调用。
