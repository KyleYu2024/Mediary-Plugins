# PT 站内信通知

插件每 6 小时检查一次 Mediary 中已启用 PT 站点的未读站内信，也可以在插件详情中手动执行。

站内信通知默认使用 [PT 站内信通知图](assets/notification.png)。

- `启用插件` 是抓取任务总开关。
- `站点 ID` 留空时检查全部已启用站点，填写多个 ID 时用英文逗号分隔。
- `标题过滤词` 支持 `|`、英文逗号和中文逗号，任一关键词命中标题即跳过通知。
- 插件通过受限接口读取站内信内容，不会获取或保存 PT Cookie。
- 已处理消息保存在插件自己的 `data/history.json` 中，用于去重。

读取详情可能会使站内信在 PT 站点上变为已读。M-Team 当前无法读取详情，因此只记录错误，不发送内容不完整的通知。
